# Requisitos Funcionales

## Ejercicio 05: Identificar requisitos funcionales

### Objetivo
Identificar las funcionalidades que el sistema debe proporcionar a partir de las historias de usuario.

---

## Listado de requisitos funcionales

| ID | Requisito funcional |
|----|---------------------|
| RF01 | El sistema debe permitir buscar productos mediante criterios de búsqueda. |
| RF02 | El sistema debe permitir consultar la información y disponibilidad de los productos. |
| RF03 | El sistema debe permitir registrar y actualizar productos en la plataforma. |
| RF04 | El sistema debe permitir agregar, modificar y eliminar productos del carrito de compra. |
| RF05 | El sistema debe permitir generar un pedido a partir de los productos del carrito. |
| RF06 | El sistema debe permitir consultar los pedidos realizados y su estado. |
| RF07 | El sistema debe permitir registrar, actualizar y desactivar sellers de la plataforma. |
| RF08 | El sistema debe permitir consultar el detalle de un pedido realizado. |

---

## Requisitos funcionales complementarios (propuestos)

| ID | Requisito funcional |
|----|---------------------|
| RF09 | El sistema debe permitir el registro e inicio de sesión de clientes y sellers. |
| RF10 | El sistema debe permitir procesar el pago de un pedido mediante una pasarela de pago. |
| RF11 | El sistema debe permitir generar comprobantes de pago (boleta/factura) por cada pedido. |
| RF12 | El sistema debe permitir gestionar la información de envío y entrega de los pedidos. |
| RF13 | El sistema debe permitir enviar notificaciones al cliente sobre el estado de su pedido. |
| RF14 | El sistema debe permitir al seller consultar las ventas de sus productos. |
| RF15 | El sistema debe permitir al administrador gestionar los productos publicados en la plataforma. |
| RF16 | El sistema debe permitir al administrador visualizar métricas de la plataforma. |
| RF17 | El sistema debe permitir consultar información de productos y stock desde el ERP. |

---
